# 开发者工具箱

免费、快速、开源的开发者工具集合

## 功能特性

- ✅ **JSON格式化** - 格式化、校验、压缩、转义
- ✅ **二维码生成** - 输入文本生成SVG二维码
- ✅ **Markdown编辑** - 实时预览、HTML输出、下载

## 技术栈

- React 18 + TypeScript
- Tailwind CSS
- Vite

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 运行测试
npm test

# 构建生产版本
npm run build
```
