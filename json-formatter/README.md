# JSON Formatter

免费、快速、开源的JSON格式化工具

## 功能特性

- ✅ JSON格式化与美化
- ✅ JSON语法校验与错误定位
- ✅ JSON压缩
- ✅ JSON转义/反转义
- ✅ 一键复制
- ✅ 完全免费、开源

## 技术栈

- React 18 + TypeScript
- Tailwind CSS
- Vite

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 运行测试
npm test

# 构建生产版本
npm run build
```
